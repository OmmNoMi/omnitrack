# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
To report a security vulnerability, please email **omnitrack@ommnomi.com** or **security@ommnomi.com** directly rather than filing a public issue. We will acknowledge receipt within 24 hours.

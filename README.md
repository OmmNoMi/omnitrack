## 🎯 Tailored for How Modern Teams Actually Work

### 🏢 1. For Multi-Client Companies & Digital Agencies
* **The Reality**: Your team doesn't work on one single thing all day. Associates switch between Client Alpha in the morning, Client Beta in the afternoon, and internal product work in between.
* **The OmniTrack Solution**:
  - **Instant Context Switching**: Select any client deliverable in the searchable picker; project, billing rates, and activity nature bind automatically.
  - **Zero Billable Leakage**: Every 10-minute micro-session is captured with concrete milestone notes. Never lose another unbilled hour.
  - **Automated Client Timesheets**: When a work block completes, it rolls up into official billing timesheets for 1-click invoicing in ERPNext.

### 💻 2. For Remote Associates, Freelancers & Flexible Workers
* **The Reality**: The 9-to-5 contiguous day is obsolete. Knowledge workers have energy peaks—a 3-hour morning sprint, an afternoon family break, and a 2-hour late-night focus session.
* **The OmniTrack Solution**:
  - **Flexible Commitment Hours**: Set contracted targets (e.g., 6h/day or 30h/week) and book split shifts when your cognitive energy is highest.
  - **Discontinuous Split-Shifts**: Seamlessly schedule morning, afternoon, and night blocks. Spanning midnight? Our engine automatically handles the day boundary without penalizing your attendance.
  - **Full-Focus Mode (<kbd>Shift + S</kbd>)**: Elevates your active timer into a clean, distraction-free modal window so you can stay in the flow state.

### 🤝 3. For Clients (Radical Transparency & Trust)
* **The Reality**: Clients hate receiving invoices that say *"Consulting — 40 Hours"* with zero proof of what was actually built.
* **The OmniTrack Solution**:
  - **Milestone-Level Audit Logs**: Clients can review timestamped micro-notes recorded every 10–15 minutes during active work.
  - **Dedicated Client Portals**: Granular permissions ensure clients see live progress on public deliverables (`custom_is_public_deliverable = 1`) without accessing internal company data.

## 🏛️ The Four Core Nouns (Simple, Clear & Honest)

OmniTrack organizes all workforce activity into four clear, intuitive tiers:

```
  📁 PROJECT (Top-Level Ownership & Billing Container)
      │  ERPNext `Project` or OmniTrack Workspace
      │  Answers: "FOR WHOM is this work being done?"
      │
      └── 🎯 TASK / DELIVERABLE (The Multi-Day Actionable Goal)
            │  ERPNext `Task`, Frappe Core `ToDo`, or OmniTrack `work_item`
            │  Answers: "WHAT specific goal is being delivered?"
            │
            ├── 📅 PLANNED WORK BLOCK (The Calendar Commitment: "When I plan to work")
            │     │  DocType `Planned Work Block` (PWB-YYYY-#####) · Immutable once past
            │     │  Answers: "WHEN did the associate promise to work?"
            │     │
            │     ├── ⏱️ WORK SESSION 1 (Execution Reality: "What actually happened")
            │     │     Live stopwatch punch + progressive micro-line notes
            │     │     Answers: "WHAT WAS DONE during this active sitting?"
            │     │
            │     └── ⏱️ WORK SESSION 2 (Subsequent sitting against same commitment)
            │           Incremental progress log appended directly to parent block
            │
            └── 📅 NEXT PLANNED WORK BLOCK (Discontinuous Split Shift / Future Sitting)
                  └── ⏱️ WORK SESSION 3 (Evening execution sitting)
```

### Entity Taxonomy & Purpose:
1. **📁 Project**: The macro-level billing and client contract umbrella. You don't work directly on a Project for 30 minutes; it is the financial and organizational container.
2. **🎯 Task / Deliverable**: The specific deliverable assigned to an associate (e.g., *"Build Searchable Dropdown"*). A task typically spans multiple days and requires multiple sittings.
3. **📅 Planned Work Block**: A reservation on an associate's daily calendar for a specific date and time window (e.g., *Sunday 14:00–16:00*). It represents **commitment**. Once yesterday has elapsed, historical blocks are **permanently locked**.
4. **⏱️ Work Session**: The physical reality of sitting at your desk running the timer. It is a child record inside the Planned Work Block holding start/end timestamps, elapsed time, and progressive milestone notes.

## 💎 The Five Pillars of OmniTrack Power

### 1. ⏱️ The 2-Pane Focus Workstation (`/omnitrack`)
A dedicated, lightning-fast web workstation designed for deep, uninterrupted work without Desk clutter.
* **Ergonomic 2-Pane Layout**: The Left Pane holds your current operational focus (active digital timer, project, deliverable). The Right Pane is your rapid micro-logger where you record milestones every 5–10 minutes with a single <kbd>Enter</kbd> keystroke.
* **Intelligent Deliverable Picker**: Seamlessly search open tasks and client deliverables. Selecting an item automatically sets the project, billing category, and bi-directionally links to your calendar.
* **Full-Focus Elevation Mode (<kbd>Shift + S</kbd>)**: Tap <kbd>Shift + S</kbd> or click the header timer to elevate your active session into a clean, distraction-free modal window so you stay in the flow state.
* **Instant Multi-Device Sync**: Start a timer from your mobile phone while on transit; your desktop workstation reflects the change instantly without requiring a page refresh (powered by real-time Socket.IO events).
* **Accidental Punch Protection**: Two-step Discard action lets you cancel false starts without polluting official timesheets, paired with confirmation guards against submitting blank logs.

### 2. 📅 24-Hour Split-Shift & Flexible Schedule Engine
Say goodbye to the fiction that modern knowledge work fits into a single contiguous 9-to-5 box.
* **Discontinuous Split-Shifts**: Effortlessly schedule morning, afternoon, and evening blocks around your life and peak energy windows.
* **Midnight-Crossing Boundary Engine**: Working late past midnight? OmniTrack automatically splits hours across the calendar boundary so late-night sessions don't trigger false "Absent" or "Late" attendance penalties.
* **Smart Overlap Handling**: When multiple blocks overlap, OmniTrack automatically packs them into clean side-by-side columns and calculates true unique hours—so you never get impossible 30-hour days.
* **Drag-and-Drop Calendar**: Easily drag blocks across days or resize them with 15-minute magnetic snapping to update your daily plan.

### 3. 🎯 Plan Adherence: Promise vs. Reality (Without Spyware)
How well is your team delivering on its commitments? OmniTrack gives leadership and clients a real-time **Plan Adherence Score**:

> **Plan Adherence** compares the hours your team actually spent on scheduled client priorities versus hours diverted to unexpected fires or interruptions.

* **🎯 100% Adherence**: Complete focus. All time spent today was delivered directly against planned client commitments.
* **⚡ 75% Adherence**: Healthy velocity. 75% of work went to planned deliverables, while 25% was spent handling urgent unplanned tasks.
* **Authentic Unplanned Tracking**: Spontaneous firefighting is clearly marked as `Unplanned Work`. You see exactly what derailed a project without blaming the associate.
* **Live Health Badge**: A quick pulse badge in the header shows your day's adherence score at a glance (e.g. `85%`).
* **Underplanned & Overdue Radar**: Automatic scanning surfaces past-due or under-allocated tasks with instant one-click actions (`Plan in Calendar` or `Start Now`).

### 4. ⚖️ Fair-Play Governance (Zero Cheating, Zero Micromanagement)
Professional trust requires clear, tamper-proof ground rules:
* **The 2-Day Timesheet Window**: Associates can log and adjust their own work sessions for **today and yesterday**. Any historical back-filling further in the past requires manager approval, keeping records fresh and audit-ready.
* **Locked Past Commitments**: Once a day has passed, the original calendar plan cannot be changed retroactively. You can never "fake" that you planned something yesterday—preserving complete honesty between planning and execution.

### 5. 🌐 Seamless Multi-Site Sync & Automatic Attendance
* **Multi-Branch Synchronization**: Seamlessly sync projects and timesheets between a central headquarters and remote branches or subsidiaries using secure cryptographic replication (HMAC-SHA256).
* **Automatic Attendance from Actual Work**: Generates clean HR attendance records directly from validated work sessions and check-in logs—with smart midnight cutoffs that respect night owls and graveyard shifts.
* **Dual-Mode Engine**: Operates independently on pure Frappe Framework or with full ERPNext Project, Task, and Timesheet integration.

### 6. 🤖 Ambient AI Assistant & Frappe Assistant Core (FAC) Bridge
* **Any Employee, Any LLM**: Manage schedules and log work naturally from Cursor, VS Code, Claude Desktop, ChatGPT, Raycast, or Slack/Telegram bots.
* **Purpose-Built MCP Tools**: Exposes 6 native domain tools (`omnitrack_get_my_workspace`, `omnitrack_plan_work_blocks`, `omnitrack_log_work_session`, `omnitrack_quick_create_task`, `omnitrack_quick_timer_action`, `omnitrack_get_eod_reconciliation`).
* **Zero Form-Filling**: Transform git commits, terminal actions, and conversational summaries directly into compliant ERPNext timesheets with mandatory deliverable notes.
* **Built-in Invariant Safeguards**: AI agents are strictly bounded by OmniTrack's 2-day modification horizon and immutable past planned blocks.

## 🚀 Quick Start & Installation

### 1. Installation via Frappe Bench

```bash
# Navigate to your frappe-bench directory
cd /path/to/frappe-bench

# Get the OmniTrack app
bench get-app https://github.com/OmmNoMi/omnitrack.git

# Install onto your target site (Standalone Frappe or ERPNext)
bench --site [your-site-name] install-app omnitrack

# Run database schema migrations
bench --site [your-site-name] migrate

# Clear application and website cache
bench --site [your-site-name] clear-cache
bench --site [your-site-name] clear-website-cache
```

### 2. Frontend Development & Building Assets

OmniTrack uses Vite and Tailwind CSS for high-performance frontend compilation:

```bash
# Navigate to the OmniTrack app directory
cd apps/omnitrack

# Install frontend dependencies
npm install

# Compile production bundles
npm run build
```

## 🧪 Testing & Verification Protocols

OmniTrack adheres to strict zero-regression engineering standards:

### 1. Spec-Compliant HTML5 Tree Verification
Because Frappe in-DOM templates (`www/*.html`) are parsed by the browser's native HTML5 parser, OmniTrack includes an automated tree-construction validator using `html5lib`:

```bash
# Verify all portal templates parse cleanly without premature tag closures
env/bin/python apps/omnitrack/scripts/check_www_html.py
```
